## v1.2.0 更新内容

### 🐛 修复
1. **小组件无法显示**
   - 新增 WidgetCapability 预检：API 级别 / Launcher 支持 / 电池优化 / 厂商限制（华为/小米/OPPO/荣耀/vivo）
   - `requestPinAppWidget` 成功/失败路径均有反馈，不再静默失败
   - 失败时展示手动教程：长按桌面 → 小组件 → TaskFlow → 添加
2. **编辑任务页面标题重复**
   - 编辑任务页仅保留 TopAppBar 中的"编辑任务"标题，表单内重复标题已移除
3. **日期选择器高亮一致**
   - 移除错误的 `todayColor` 参数（Material3 1.3.0 不支持），今日高亮采用内置配色

### ✨ 新增
1. **设置页添加小组件按钮**
   - "添加桌面小组件"区块 + 小组件状态（已添加/未添加）
   - 自动添加 + 手动添加两个入口
2. **首次/后续任务创建的 Widget 交互**
   - 第一次创建任务 → 弹窗"是否创建桌面小组件？"
   - 第二次及以后 → 弹窗"是否将此任务添加到桌面小组件？"
3. **统计折线图**
   - 数据源改为真实的 Task 完成记录（Room Flow：`observeDailyCompletions`）
   - 完成任务后折线图当天数据点实时提升
   - Y 轴动态：≤5→0-5，12→0-15，50→0-60（按最大值 + 顶部空间自适应）
   - 标题自动生成："YYYY年MM月任务完成趋势"，切换月份同步更新
